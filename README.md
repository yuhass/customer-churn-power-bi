# Customer Churn Analysis in Power BI

## Project Overview

This project analyzes customer churn using Power BI to identify key drivers.

## Tools Used

- Power BI
- Power Query
- DAX

## Dashboard Preview
![Customer Churn Dashboard](churn-dashboard.png..png)

## Key Findings
- Customers on month-to-month contracts have the highest churn rate at 42.71%.
- Customers with zero to twelve months tenure have the highest churn rate at 47.44%.

## Recommendtaions
- Encourage month-to-month to move to longer contracts with incentives.
- Focus on retention in the first twelve months
- Provide targeted support to high-risk groups.

## Dataset

This project uses a customer churn dataset from Kaggle containing customer demographics, account information, services, contract types, payment methods, tenure, monthly charges, and churn status.

**Source:** [Telco Customer Churn Dataset on Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)
